# 3. 使用 Web UI

Web UI 是 DeepSeek Harness 最直观的入口。本章假设你已经按[第 2 章](/guide/02-install)把服务器跑起来了（默认 `http://127.0.0.1:3080`）。

## 打开界面

浏览器访问 `http://127.0.0.1:3080`。你会看到：

- 顶部的会话输入区（composer）
- 左侧的会话列表 / 工作区选择
- 右上角的 **Settings（设置）**

首次使用时，需要完成两件事：**配置模型** 和 **选择工作区**。

## 1. 配置模型

打开 **Settings → Models**：

1. 在 **DeepSeek** 卡片里输入 API key，保存。
2. 保存后模型路由立即可用，**无需重启服务器**。

API key 是**只写**的：保存后页面只会收到脱敏的描述符，不会回传明文密钥。密钥本身存入 `$DSH_HOME/.credentials.yaml`，设置里只保留引用。

其它 provider（Anthropic、OpenAI、Bedrock、Vertex、Azure、Codex）和自定义 OpenAI 兼容端点，见[第 4 章](/guide/04-models)。

## 2. 选择工作区

点击 **Choose workspace**（选择工作区），把项目目录加进去并选中。**未选择工作区前，会话输入区不可用**。

工作区（workspace）是 Agent 的默认文件系统位置。`dsh` 进程的调用目录是默认工作区根，但一个全新的 Web UI 在你添加之前没有任何已选工作区。

## 3. 运行第一个任务

选好工作区后，开一个会话，输入：

> 总结这个仓库，找出它的主要包。

Agent 会：

- 读取工作区文件
- 执行命令（如 `ls`、`rg`）
- 必要时委派子代理
- 维护计划（plan）与待办清单

在活跃的权限策略下，Web UI 会在需要审批的操作前弹窗询问（审批机制的细节见[「策略与交互」解读](/deepdive/11-policy-interaction)）。

## 4. 会话与模型选择

- **模型选择器**：选中的模型会成为新会话的默认模型。已发过请求的会话会保留自己日志里记录的模型，不受后续默认值影响。
- **切换语言/外观**：右上角支持简体中文/英文、浅色/深色主题。
- **继续会话**：会话列表里点开即可继续；所有会话内容都以日志形式持久化，可跨重启恢复。

## 你看到的背后是什么

Web UI 是一个"浏览器半边 + Node 半边"的分布式 Cordis 组合：

- **Host（Node 进程）**：跑模型、工具、会话、持久化、沙箱、审批等。
- **Client（浏览器）**：跑 UI shell、wire 通信、对象服务、Slots 插槽、`ui-*` 插件。

两者通过私有 JSON-RPC 通信。你在界面上的每一次操作，最终都会变成对 Host 服务的调用，并触发会话日志事件。这个机制的完整拆解见[「平台接入与 SDK」解读](/deepdive/12-platform)。
